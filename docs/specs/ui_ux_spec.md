## 0. 제약 (구현 측에서 고정)

- 빌드 도구 없음. Vanilla JS(ES 모듈) + CSS 한 파일(`src/styles.css`). 외부 라이브러리·웹폰트를 추가하려면 먼저 요청한다.
- 색·간격은 `src/styles.css`의 `:root` 토큰으로만 바꾼다. 라이트/다크 두 벌이 필요하다.
- 데이터 구조와 문항 유형은 `quiz_flow.md`가 기준이다. 새 문항 유형이 필요하면 그 문서에 먼저 제안한다.
