# Quiz Flow — 구현 기준 문서

Claude Code가 관리한다. 엔진(`src/engine/`)이 실제로 하는 일을 적은 문서이고, Antigravity가 UX를 설계할 때 참고하는 계약이다.

## 하루 세트 (10문항, 쉬운 것 → 어려운 것 순서)

| # | 파트 | 유형 `type` | 내용 | 채점 |
|---|---|---|---|---|
| 1 | 다이어리 | `choice` | 오늘의 단어 → 뜻 고르기(4지선다) | 자동 |
| 2 | 다이어리 | `choice` | 뜻 → 오늘의 단어 고르기(4지선다) | 자동 |
| 3–4 | 다이어리 | `cloze` | 예문 빈칸에 오늘의 단어 직접 쓰기 | 자동(대소문자·문장부호 무시) |
| 5–6 | 다이어리 | `write` | 주요표현을 한국어 뜻만 보고 영작 | 모범 답안 공개 후 자기 판정 |
| 7–8 | 구동사 | `cloze` | 문장 전체와 해석을 보고 빈칸 직접 쓰기 | 자동 |
| 9–10 | 구동사 | `write` | 한국어 해석을 보고 문장 전체 영작 | 자기 판정 |

구동사는 문장에 따라 뜻이 달라지므로 보기에서 고르는 문항은 내지 않는다(사용자 요청, 2026-11-10).

## 채점 결과와 노션 기록

- 결과 모달은 문항별 ○/×, 정답을 보여 주고, 틀린 문항에는 내 답과 설명을 함께 보여 준다.
- "채점 결과 복사 (노션 기록용)" 버튼은 결과를 마크다운으로 클립보드에 복사한다(`resultMarkdown`).
- **구글 시트 자동 기록:** 퀴즈를 끝내면 결과를 사용자의 구글 시트 「Daily English Quiz 기록」으로 보낸다(`src/engine/logsync.js`). 시트에 붙인 Apps Script 웹 앱이 "요약"·"문항" 탭에 줄을 추가한다. 연동 링크(주소 + 키)는 코드에 넣지 않고 기기의 `localStorage`(`logConfig`)에만 둔다. 홈 맨 아래 "기록 저장" 링크에서 붙여 넣거나, 사이트 주소 뒤에 `#log=<인코딩한 링크>`를 붙여 열면 저장된다. 전송에 실패한 기록은 `outbox`에 남겨 다음 접속 때 다시 보낸다. 같은 기록(`날짜-기기ID`)은 스크립트가 한 번만 저장한다.
- 앱은 정적 사이트라 노션에 직접 쓰지 못한다. 복사한 내용을 노션 「Daily English Quiz 학습 기록」(Study 하위) 페이지의 "시험 기록"에 붙여 넣거나, Claude에게 붙여 주면 대신 기록한다.

- **갱신 시각:** 학습일은 기기 현지 시각 **오전 8시**에 바뀐다. 세트는 학습일을 시드로 만들어 `localStorage`에 저장하므로 같은 날에는 새로고침해도 같은 문제다.
- 최근 5일에 나온 항목은 가능한 한 피하고, 같은 표현·같은 구동사는 하루에 한 번만 나온다.
- 빈칸 쓰기 1번은 복습 예정 항목이 없으면 최근 일기 10건에서 뽑는다.

## 문항 설계 근거

- **고르기보다 쓰기 비중을 높였다(10문항 중 8문항).** 어휘를 실제로 쓰는 능력은 보기에서 고르는 연습보다 직접 떠올려 쓰는 연습에서 더 잘 길러진다는 연구 결과를 따랐다. 4지선다는 뜻을 구별하는 초반 단계에만 쓴다.
- **구동사는 반드시 예문 속에서 묻는다.** 구동사는 문맥과 함께 익힐 때 학습 효과가 더 크다.
- **틀린 항목은 간격을 벌려 가며 다시 낸다.** 간격 반복은 구동사 학습에서도 효과가 보고됐다. 다만 처음부터 못 떠올리면 효과가 없으므로 힌트 버튼을 둔다.

## 복습

- **간격 반복:** 틀린 항목은 1일 뒤 오늘의 퀴즈에 "복습" 표시로 다시 나온다. 맞힐 때마다 3 → 7 → 14일로 간격이 벌어지고, 14일 뒤에도 맞히면 졸업한다. 틀리면 1일로 돌아간다. 복습 항목은 직접 쓰는 자리(빈칸 쓰기, 영작)에 먼저 배치된다.
- **복습 노트:** 틀린 문항이 쌓인다. "지금 다시 풀기"로 언제든 다시 풀 수 있고, 맞히거나 "외웠어요"를 누르면 빠진다. 다시 풀기는 오늘 점수와 간격 반복 일정에 영향을 주지 않는다.

## 데이터

### `docs/data/diary.json` — Notion `[2026]English Diary` 59건 + `[2025]English Diary` 96건

2025 DB는 2025-08-05 ~ 12-31분만 쓴다(6~7월은 속성이 비어 있다). 2025는 예문이 "비고" 칸에 있고, 단어 없이 주요 표현만 있는 날이 많다.

| 필드 | 출처(2026 / 2025) | 설명 |
|---|---|---|
| `id` | 날짜 / 날짜 1 | `YYYY-MM-DD` |
| `title` | 제목 / 없음 | 일기 제목. 2025는 제목이 날짜라서 `null` |
| `word` | Daily word / daily word | 오늘의 단어. 없으면 `null`(영작 문항에만 쓰인다) |
| `cloze` | 예문 / 비고 또는 주요 표현 | 정답 부분을 `{{ }}`로 감싼 문장. 원문의 문법 오류는 교정했다. 없으면 `null` |
| `expr` | 주요표현 / 주요 표현 | 영작 모범 답안. 없으면 `null` |
| `meaning`, `clozeKo`, `exprKo` | Claude 작성 | 한국어 뜻·해석 |

### `docs/data/phrasal_verbs.json` — Google Docs 「구동사 활용법 총정리 (Ver 01 ~ Ver 10)」

`groups` 배열. 구동사 107개, 예문 180개.

| 필드 | 설명 |
|---|---|
| `phrase`, `meaning` | 예: `be behind`, `뒤처지다 / 밀리다` |
| `examples` | `[영어 예문, 한국어 해석]` 쌍의 배열. 영어 예문에서 전치사 부분을 `{{ }}`로 감싼다 |

데이터를 고친 뒤에는 `python scripts/sync_notion.py --check`로 규격을 확인한다.

## 저장 키 (`localStorage`, 접두어 `deq.v2.`)

- `day.<학습일>`: 그날의 문항과 답
- `history`: 날짜별 점수(최대 60일) — 연속 학습일 계산
- `srs`: 간격 반복 일정 `{ "word:<일기id>" | "expr:<일기id>" | "pv:<예문id>": {box, due} }`
- `review`: 복습 노트(문항 전체 포함)
